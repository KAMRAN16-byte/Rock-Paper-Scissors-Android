# Rock Paper Scissors Game 🎮

A simple Android implementation of the classic **Rock Paper Scissors** game built using **Kotlin** and **Jetpack Compose**. Players choose Rock, Paper, or Scissors while the computer generates a random move and determines the winner instantly.

## 📱 Features

- Play Rock, Paper, Scissors against the computer
- Random computer move generation
- Automatic winner determination
- Display of player and computer choices
- Reset game functionality
- State-driven UI using Jetpack Compose
- Clean and beginner-friendly interface

## 🎮 Gameplay

1. Select either:
   - Rock
   - Paper
   - Scissors
2. The computer randomly chooses its move.
3. The result is displayed:
   - Win
   - Lose
   - Draw
4. Press Reset to play again.
